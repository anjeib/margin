### Проверка API 36 на эмуляторе `margin35` (Android 15)

Новая сборка встала поверх 0.93 с теми же данными. Проверено: лента, карточка дела, «Дневник», «Содержание», «Настройки», тёмная тема, окно «Поделиться → В Margin»; «назад» — и кнопкой, и жестом от края (при API 36 жест «назад» идёт через предиктивный back; все `BackHandler` сработали, цепочка Настройки → Содержание → Дела → рабочий стол); края экрана (edge-to-edge) — как раньше; точный будильник — уведомление пришло в 12:00:01 с кнопками «Готово / Через час», «Готово» отметило дело; виджет «Сегодня» сразу обновился. Падений в журнале нет.

**Не проверено на Android 16.** Поведение targetSdk 36 включается только на Android 16, а `margin35` — Android 15. Образ Android 16 (несколько ГБ) не поставить: на диске свободно 3,5 ГБ. По коду изменения Android 16 Margin не задевают:
- предиктивный «назад» включён по умолчанию — Margin везде использует `BackHandler` (androidx.activity 1.10.1), `onBackPressed` нигде нет;
- отказаться от edge-to-edge больше нельзя — Margin и так рисует под системными панелями (`enableEdgeToEdge()`), атрибута отказа нет;
- на экранах от 600 dp (планшеты, раскладушки) игнорируется запрет поворота — у Margin запретов поворота нет, ничего не меняется;
- `elegantTextHeight`, служб переднего плана, `scheduleAtFixedRate` в коде нет; точные будильники в Android 16 не менялись.

Лучшая проверка — поставить сборку с API 36 на свой moto g75 (Android 16) или получить её через закрытое тестирование Play.

## Решить владельцу

1. **Точные будильники**: вариант 1 (оставить `USE_EXACT_ALARM` + декларация) или вариант 2 (`SCHEDULE_EXACT_ALARM` с запросом — правка кода до загрузки в Play). Подробно — `exact-alarm.md`.
2. **«Безопасность данных»**: вариант А (рекомендую) или Б — `data-safety.md`.
3. **Какую сборку грузить в Play.** Черновой AAB — это код 0.93 с API 36 и номером 93, а в RuStore лежит 0.93 с API 35. Для закрытого теста его можно загрузить как есть. Для выпуска лучше следующая версия по вашей команде (с API 36 и, если выберете, с вариантом 2 будильников) — одна и та же сборка в оба магазина.

## Что сделать руками в Play Console

1. **Аккаунт разработчика** — play.google.com/console, взнос $25 (карта, которую принимает Google; российские не проходят — например, казахстанская).
   - **Личный аккаунт**: проверка личности (документ), подтверждение телефона и почты, подтверждение доступа к Android-устройству через приложение Play Console. Для новых личных аккаунтов перед выпуском обязателен **закрытый тест: не меньше 12 тестеров, подписанных непрерывно 14 дней**, потом заявка на доступ к выпуску (короткая анкета о тесте). Проверка заявки — обычно до 7 дней.
   - **Аккаунт организации** (ИП/юрлицо): нужен номер D-U-N-S, зато без обязательного теста 12 × 14. Для будущих встроенных покупок понадобится платёжный профиль в стране, где Google платит разработчикам (из России — нет; например, Казахстан).
2. **Создать приложение**: название «Margin — ежедневник и дневник», язык по умолчанию — русский, «Приложение», «Бесплатное».
3. **Подпись своим ключом** — строго до первой загрузки AAB: `signing.md`.
4. **Контент приложения**: политика https://marginapp.ru/privacy.html, реклама, доступ, рейтинг, аудитория, «Безопасность данных», точные будильники и др. — `app-content.md`, `data-safety.md`, `exact-alarm.md`.
5. **Карточка магазина**: тексты из `listing.md`, графика из `graphics/`, категория, почта post@marginapp.ru, сайт https://marginapp.ru.
6. **Закрытое тестирование**: трек «Закрытое тестирование» → список тестеров (адреса Gmail или группа Google, лучше 15–20 человек с запасом — кто-то отпишется), загрузить AAB, отправить на проверку, разослать ссылку-приглашение. Тестеры принимают приглашение и ставят приложение из Play; не отписываться 14 дней подряд. Попросить их пользоваться и писать отзывы — заявка на выпуск спрашивает, как шёл тест.
7. **Заявка на доступ к выпуску** (Dashboard → «Подать заявку на доступ к рабочей версии»), после одобрения — выпуск в «Рабочую версию», выбор стран.

Перед каждой загрузкой новой версии: `JAVA_HOME=/opt/homebrew/opt/openjdk@17 ./gradlew bundleRelease` → `app/build/outputs/bundle/release/app-release.aab`.
