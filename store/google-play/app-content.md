# «Контент приложения»: возрастной рейтинг и остальные декларации

Play Console → приложение → «Контент приложения» (Policy → App content). Всё, кроме «Безопасности данных» (`data-safety.md`) и точных будильников (`exact-alarm.md`).

## Возрастной рейтинг (анкета IARC)

- Адрес для связи по рейтингу: post@marginapp.ru
- Категория: **«Все другие типы приложений»** (All other app types) — не игра, не соцсеть, не магазин.

| Вопрос анкеты | Ответ |
|---|---|
| Насилие, кровь, страшные сцены | Нет |
| Сексуальное содержание, нагота | Нет |
| Ненормативная лексика, грубый юмор | Нет |
| Алкоголь, табак, наркотики | Нет |
| Азартные игры, имитация азартных игр, ставки | Нет |
| Можно ли пользователям общаться или обмениваться контентом **друг с другом** в приложении | Нет — переписки и обмена между пользователями нет; «Поделиться» отдаёт текст в другие приложения самим человеком |
| Передаёт ли приложение точное местоположение другим пользователям | Нет |
| Покупки цифровых товаров | Нет |
| Неограниченный доступ в интернет (встроенный браузер, поиск) | Нет — ссылки открываются во внешнем браузере |
| Контент, созданный пользователями, виден другим людям | Нет — всё хранится на телефоне |
| Приложение — веб-браузер или поисковик | Нет |

Ожидаемый итог: **3+ / PEGI 3 / «для всех»** (в России в карточке — 0+ или 3+, как и в RuStore).

## Целевая аудитория и контент

- Возраст целевой аудитории: **18 и старше** (можно добавить 16–17). Не отмечать возрасты до 13 — иначе приложение попадает под правила Families (дети) с отдельными требованиями.
- Может ли приложение невольно привлекать детей: **Нет**.

## Магазин: страна и цена

- Цена: **бесплатно**. Внимание: бесплатное приложение потом нельзя сделать платным в Play — только встроенные покупки (они и планируются).
- Страны: на выбор владельца. Интерфейс только русский, поэтому разумно: Россия, Казахстан, Беларусь, Армения, Грузия, Узбекистан, Кыргызстан и др. страны, где говорят по-русски, или «все страны».
- Учтите: в России Google Play работает, но приём оплат разработчику из России закрыт — для будущих встроенных покупок нужен платёжный профиль в стране, где Google платит (например, Казахстан).
