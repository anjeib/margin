# Margin — ИИ-ежедневник для Android

Личный ежедневник в виде мессенджера: одно поле ввода внизу, ИИ (через OpenRouter) сам превращает свободный текст и голос в задачи, подзадачи, заметки, ожидания и контакты. Kotlin + Jetpack Compose, один модуль `app`, пакет `ru.anjeib.margin`.

Владелец общается по-русски — отвечать по-русски.

## Принципы продукта (не нарушать без явной просьбы)

- **Чат прежде всего, минимум интерфейса.** 90% работы — через поле ввода. Без приоритетов, канбана, сложных фильтров, лишних ИИ-кнопок у каждой задачи.
- **Тишина вместо болтовни.** После ввода пузырь пользователя сам превращается в результат (пометка «задача/заметка/2 задачи», что именно изменилось, «Изменить · Отменить» на ~5 с, касание задерживает), затем исчезает, а элемент подсвечивается в списке. Голые подтверждения «Сохранено…» не показываются. В ленте остаются только ответы и ошибки.
- **Заметки не смешиваются со списками задач.** На «Сегодня» — одна тихая строка «Сегодня в заметках: …». Заметки — ленты датированных записей, привязаны к проекту.
- **Мягкие сроки.** «На этой неделе» = окно start..due, без ложной точности; без даты — нормально.
- **Интерфейс целиком на русском ИЛИ целиком на английском**, никогда не вперемешку. Любая новая строка добавляется в `i18n/Strings.kt` сразу в оба объекта (`Ru` и `En`). Язык по умолчанию — системный (`LangMode.Auto`).
- **Две темы**: светлая «бумага» и тёмная «тёплый уголь» + Авто. Цвета только из `Palette` (`M.c`), никаких захардкоженных цветов в экранах.
- Дизайн-референсы: `design/*.png` (v1) и `design/v2-*.png` — сверяться с ними.

- **Мысль → задача → человек** — сердце продукта (макеты `design/v3-*.png`). У задачи есть источник (`source` — исходная фраза, `noteId`/`sourceEntryId` — идея из заметки) и обещания в обе стороны (`waitingFor` — ждём от человека, `promisedTo` — пользователь обещал). Связи считаются на телефоне (`ui/Links.kt`), сводки по человеку и проекту пишет ИИ раз в день и по ↻. ИИ не придумывает роли людей: `Person.aboutFromUser` отделяет слова пользователя от догадок. Связь показывается без схем: в карточке задачи блок «Связи» — только если связь реальна: идея, из которой выросла задача, и открытые ожидания/обещания с людьми этой задачи (общий проект — не связь; своё обещание задачи живёт в поле «Обещано», не в «Связях»); строка «↳ из разговора» — только у задач без идеи; на странице проекта «✎ из идеи» в строке задачи и развёрнутый список «Идеи без задач»; в заметке у каждой записи иконка: «＋задача» или «✓ уже в задачах» (`IdeaTaskButton`, сопоставление — `tasksOfEntry`). Цепочки-схемы из макета v3-03 убраны. В заметках нет ИИ-кнопок («Конспект», «В задачи» убраны в 3.6).
- **Строки задач в списках**: название целиком (до 3 строк), под ним бледно последняя запись, затем дата/время заметнее (14sp, medium), место мельче. **Неделя** — полоска из 7 дней с точками, нажатие — показать день. **Сегодня**: раздел «Просрочено · Перенести на сегодня» (вместо плавающей кнопки), раздел «Без даты» (до 5, свайп влево — на завтра), пустой день — «Свободный день».
- **Карточка задачи**: дата и время — первыми и крупнее (`BigChip`); ниже одной тихой строкой повтор, люди, ждём/обещано, место, тег проекта последним; ещё ниже «+ время · + место · + подзадача …» только для пустого; затем блок «Вы написали» — исходная фраза, один раз приведённая в порядок быстрой моделью (`MainVm.tidySource`, `Task.sourceFixed`). Блок-форма с «не задано» пробовалась в 3.6–3.8 и убрана: пустые строки — шум.
- **Карточка человека**: имя, под ним должность · компания; контакты чипами (нажатие — позвонить/написать/открыть, долгое — изменить); тихо «+ должность · + компания · + телефон · + почта · + адрес · + MAX · + Telegram»; «Личная информация» (`Person.personal`, по факту на строку); сводка; один список «Задачи» (песочные часы и «вы обещали» в строке уже говорят направление — отдельные «Обещано вам / Вы обещали» убраны).
- **Заметки**: короткая заметка целиком становится заголовком («Посмотреть Одиссею»), длинная — заголовок + текст внутри; у заметки-заголовка своя кнопка «в задачу».
- **Настроек поведения нет.** Имя и время утренней сводки спрашиваются в чате при первом запуске (`MainVm.startSetup` / `setupAnswer`, `Settings.setupStep`), потом меняются словами («сводку в 9», «называй меня Аня») — действие `settings` в схеме. В меню нет «Обзора недели»; есть «Входящие» (`ui/InboxScreen.kt`): записанное без интернета и сохранённое без разбора, позже — письма.
- **Каждая запись с большой буквы, имена тоже** («купить хлеб у тимура» → «Купить хлеб у Тимура»): `data/Writing.kt` (`sentence`, `withNames`, `properName`), применяется в `Assistant.apply`, в ручном вводе (`MainVm`) и миграцией старых данных.
- **ИИ меняет только то, о чём сказано.** `Assistant.apply(strict = true, focus, recent)`: задачи, не упомянутые во фразе (и не открытая, и не из последних реплик), не трогаются; дата/время/повтор/«ждём» меняются, только если во фразе есть о них слова; новое обещание не сливается с повторяющейся задачей; повторы всегда стоят на ближайшей будущей дате (`onSchedule`); «заказать у X» — не ожидание. Это код, не промпт: работает при любой модели. Проверка — `GuardsTest` (офлайн).
- **Резервная копия — только Android Auto Backup в аккаунт Google** с переключателем в настройках (`data/MarginBackupAgent.kt`, ключ `googleBackup`). Копия в файл, экспорт/импорт архива и Markdown убраны по решению владельца (3.10) — не возвращать без просьбы.
- **Команды по ключевым словам — в коде, без ИИ** (`ai/Commands.kt`): глагол (добавь/добавим/запиши/создай/поставь/укажи/новая…) + объект (подзадачу, заметку, место/адрес, время, телефон, почту, telegram, участника, проект, запись, список…) или «Объект: …». Если значения хватает — делается сразу (`MainVm.runCommand`, тот же путь plan → apply → пузырь/отмена, `AiPlan.local`); если нужен смысл (даты, «к какой задаче») — уходит в ИИ с подсказкой `Commands.hint`. Без ключевых слов всё по-прежнему понимает ИИ. Тест — `CommandsTest`.
- **Поле ввода вместо маленьких окон.** «+ подзадача / место / люди / проект» в задаче и заметке переводят поле ввода в режим «Подзадача: …» с голосом (`SmartComposer(modeLabel, focusKey)`, `MainVm.sendAs`); дата/время/повтор — по-прежнему выбор.
- **Вопросов в чате нет.** Без времени/срока задача создаётся как есть, а в пузыре-результате тихо «Уточнить время / срок?» — открывает циферблат/календарь этой задачи, не нажали — уходит вместе с пузырём.
- **История задачи** (`Task.history`, `Change`, `Task.logged`): что изменилось и кто — вы / ИИ; пишется в `Assistant.apply` и в ручных правках (`MainVm.updateTask`), показывается свёрнутой в карточке. Хранится данными, а не текстом — читается на текущем языке.
- **«Не буду делать»** (`Task.dropped`) — закрыто без выполнения: не зачёркивается, помечено «не делали», в сводках — `[dropped]`. **«Сделать заметкой»** — обратный путь к «идея → задача».
- **Заметки**: свойства как у задачи без «готово» — проект, люди, место, напоминание (`Note.remindAt`, будильник через `Reminders.syncTasks` как «note:<id>»); блок «Список» (`Entry.isList`, пункты-галочки); короткая заметка — заголовком, приведённым в порядок быстрой моделью (`MainVm.tidyNote`, `Note.titleFixed`).
- **Заметка и «Записи» задачи — лента блоков** (`ui/Blocks.kt`, `BlockStream`): текст, список, фото (широко, подпись), видео (кадр, длительность, подпись), голосовое (плеер на месте + расшифровка), контакт (карточка, позвонить/написать, связан с «Людьми»), файл, ссылка (заголовок страницы). Нажатие делает блок активным → тихая «+» → ряд вставки (текст, список, фото, камера, видео, голос — запись на месте, файл, контакт) — вставка сразу после блока; долгое нажатие — изменить / подпись / вставить ниже / выше / ниже / удалить. Подписи и правки вводятся в поле ввода (режим `Fill`), не в окнах. Всё распознанное идёт в `Entry.fullText` → поиск и контекст ИИ. Текст с фото — **только по кнопке** «Распознать» у активного фото (`MainVm.photoText`): «Вставить текстом» / «Создать контакт» (визитка → `Person` + карточка контакта, `Assistant.cardPrompt`) / «Сделать задачи». Распознаётся один раз и запоминается (`Attachment.ocr`, на экране не показывается — уже видно на фото). Yandex Vision OCR (`Yandex.ocr`, роль `ai.vision.user` у `margin-app` выдана), на OpenRouter — модель с картинками. Автоматическое распознавание пробовалось в 3.13 и убрано: повтор того, что видно, и лишние траты.
- **3.15:** диктовка везде — текст; голосовое остаётся только через «+» → «Голосовое», файлом или словом «голосовое: …» в начале диктовки (`Input.gotSpeech`). «Утром/днём/после обеда/вечером» без часов → `Task.dayPart`, время не выдумывается (`clockCue`, `partOf`). Подзадачи пронумерованы в карточке и в контексте ИИ; «измени/удали подзадачу 2», «подзадача 1 готова» — команды в коде (`Commands.numbered`), действия `update_subtask`/`delete_subtask`; разговор о подзадаче не переименовывает задачу (`stepTalk`). Названный день недели побеждает ошибку модели, если в сообщении одна дата (`onSaidWeekday`). Сводки — только на главной (бриф); у человека и проекта их нет. Свойства задачи — бейджиками; дата в списках — `DatePill`. Происхождение — тихая строка «↳ из сообщения 6 окт, 17:42», текст по нажатию. Свайп влево — «Отложить» (завтра / неделя / месяц / свой срок, `MainVm.postponeTo`). Записи заметки группируются по визитам (`Entry.session`, `MainVm.startSession`); в списке заметок — число записей. Фото/видео — миниатюры 200×150 с подписью «ФОТО»/«ВИДЕО», нажатие — просмотр поверх экрана (зум, видео играет там же, PDF и текст читаются); «Сохранить на телефон» (`Files.saveToPhone`, папка Margin) и «Переслать» — в просмотре и в меню долгого нажатия. Фото поворачиваются по EXIF.
- **3.16:** под верхней строкой — разделы «Задачи · Заметки · Люди · Проекты» (`SectionRow`), у «Задач» над ними Сегодня/Неделя/Все. Меню: Входящие, Задачи, Заметки, Люди, Проекты, Календарь, Архив, Настройки (`ui/Sections.kt`: `ProjectsScreen`, `CalendarScreen` — месяц с числом задач под днём, без цветов по проектам, `ArchiveScreen`). Свайпы: заметка и человек — влево «В архив», вправо «Удалить»; блок в заметке/задаче — влево «Удалить»; всё с «Отменить» (`SwipeActions`, `MainVm.archiveNote/removeNote/archivePerson/removePerson/removeEntry`, файлы удаляются после окна отмены). Архивное не видно в списках, поиске и контексте ИИ (`Note.archived`, `Person.archived`). Адреса — с запятой перед домом (`String.address()`, «Ленина, 5»), город не обязателен; нажатие — карта по умолчанию.
- **3.17 — пересылка в Margin** (`ai/Forward.kt`, `ForwardActivity`, `ui/ForwardSheet.kt`). Чужие слова идут в очередь «Входящие» (`Queued.via/from/sentAt/comment/subject/reply`) и разбираются с рамкой «[Forwarded … message, written by X. The author's words, not the user's]» (`Forward.prompt`, правило в `Assistant.rules`): что обещает X → «ждём X»; что X просит → задача с people=[X]; «Я: пришлю…» в переписке → обещание; сведения → заметка. Источник задачи — «Марина Петрова, из Telegram: …» (`Forward.source`). Каналы:
  - **Telegram** — личный бот пользователя (токен из @BotFather в «Настройки → Пересылка»; первый написавший — владелец, чужим отвечает «личный бот»). Пока Margin открыт — long-poll 25 с (`MainVm.foreground`), в фоне — `ForwardWorker` раз в 15 мин. Пересланное одним движением склеивается в одну запись, простое сообщение прямо перед ним — комментарий; фото/файлы/голосовые до 20 МБ скачиваются. После разбора бот отвечает, что получилось (`Forward.summary`).
  - **Почта** — IMAP (`com.sun.mail:android-mail`), пароль приложения; берутся только новые письма, отправленные себе на свой адрес или на «+margin»; только чтение, в ящике ничего не помечается. Сервер по домену (`Forward.imapHost`).
  - **MAX** — личных ботов нет (только юрлица/ИП): «Копировать» → в Margin кнопка «Вставить скопированное» (смотрится только описание буфера, текст читается по нажатию). Плюс везде: «Поделиться → В Margin» (текст, фото, файлы) и «В Margin» в меню выделенного текста (`PROCESS_TEXT`) — лист поверх чужого приложения, пользователь остаётся там.
  Секреты пересылки — в отдельных prefs `forward` (не входят в резервную копию Google). Очередь разбирается под мьютексом (`Processor.drain`) — приложение и воркер не возьмут одну запись дважды. Если ИИ ответил, что менять нечего, запись во «Входящие» не дублируется.
- **3.18:** вместо ИИ-сводки на главной — блок «Обещания», собранный кодом (ждём и обещали, срок до +3 дней или просрочено; закрываются прямо в блоке; в списках ниже эти задачи не повторяются, кроме задач со временем в ленте дня). ИИ-бриф больше не строится (код `BriefCard`/`makeBrief` остался на случай возврата). Бейджи: «Обещание · Вам от Марины» / «Виктору от Вас» (`PromiseBadge`, склонение имён `String.dative()/genitive()` в `data/Writing.kt`, компании не склоняются), люди — бейджем с полным именем (`PersonBadge`) вместо буквы. «Люди» → «Контакты» во всём интерфейсе (люди и компании). Задача из идеи «Посмотреть» в заметке «Одиссея» → «Посмотреть Одиссею» (`Task.bareFromNote`, `String.accusative()`, правило в `ideaPrompt`). Окно «В Margin»: приложение-источник по имени (Gmail, Telegram…), отправитель из текста (`Forward.sender`: «От: Имя <почта>», шапка Яндекса, копия Telegram, «ООО …») с «+ контакт» (`Forward.addContact`), внизу обычное живое поле ввода (`SmartComposer(sendEmpty = true)`). Отправителя из Gmail «Поделиться» не даёт — для реального механизма нужна пересылка письма (IMAP) или своя почта Margin.
- **3.19:** туториал — 4 экрана только о главном, с настоящими строками задач вместо описаний (пишите как думаете → результат; жесты; если понял не так — «Отменить» и команды; разрешения). Подробности — «Помощь» в меню под «Настройками» (`ui/Help.kt`, содержание — `Strings.helpSections`: как писать, разделы, обещания, внутри задачи и заметки, команды, жесты, связи, пересылка, голос и файлы). Команды «Исправить: …» (меняет существующее; действия `create_*` из ответа выбрасываются кодом) и «Добавить контакт: …». Счётчик «Отмены после ИИ» по местам (главная / в задаче / заметки) — в разделе разработчика (`MainVm.aiStats`, prefs `stats`): по нему решать, где нужны правила по умолчанию.
- **Один факт на экране — один раз.** Если «ждём от Димы» уже есть в сводке или в строке задачи, отдельный блок для этого не нужен. Перед добавлением блока проверить, не повторяет ли он то, что уже видно.

## Стиль

- Шрифты: Playfair Display (заголовки, `Type.display/title/cardTitle`), Inter (текст). Один акцент — терракота `c.accent`, мягкий фон акцента `c.accentSoft`.
- Тексты коротко и спокойно, без эмодзи и восклицательных знаков (кроме служебных значков ✎ ↻ 📎).
- Код: стиль как в окружающих файлах; комментарии короткие, объясняют «почему».

## Устройство

```

ai/OpenRouter.kt    HTTP-клиент: chat (с картинками), transcribe (WAV), список моделей, проверка ключа
ai/Processor.kt     вложения → куда положить, заметка «Входящие», офлайн-очередь + QueueWorker
ai/Forward.kt       пересылка: свой бот Telegram, письма себе (IMAP), рамка «чужие слова» для ИИ, ForwardWorker

data/Models.kt      Task, Subtask, Entry, Attachment, Note, Person, Repeat, Queued, AppData (+ migrated())
data/Store.kt       всё состояние в одном JSON (filesDir/margin.json), атомарная запись

data/Writing.kt     заглавные буквы в записях и именах
data/Dates.kt       подписи дат на двух языках
voice/LocalWhisper  офлайн-распознавание: whisper.cpp через JNI, модели качаются по запросу
notify/Reminders    точные будильники, утро/вечер, кнопки «Готово / Через час»
ui/MainVm.kt        вся логика экрана: send() по областям (Main / InTask / Notes), превью, отмена
ui/App.kt           навигация, меню, вкладки со счётчиками
ui/Tray.kt          лента над полем ввода: пузырь → результат
ui/TasksScreen.kt   Сегодня / Неделя / Все (обзор по срокам или проектам) / Выполнено / проект
ui/TaskSheet.kt     карточка задачи: лист снизу всегда на 92% экрана (минус клавиатура), строка свойств, «Связи», «Записи», своё поле ввода с ИИ
ui/NotesScreen.kt, PeopleScreen.kt, InboxScreen.kt, Search.kt, Onboarding.kt, SettingsScreen.kt, Input.kt (поле ввода, «+», диктовка)
app/src/main/cpp    JNI-мост к whisper.cpp (исходники в third_party/whisper.cpp)
```

Поток ИИ: `MainVm.send()` → `Assistant.systemPrompt()` (правила + схема + контекст: задачи, заметки, люди, календарь) → `Llm.complete()` (пустой/испорченный ответ — повтор в `Processor.askPlan`) → `Assistant.parsePlan()` → `Assistant.apply(data, plan, source, strict, focus, recent)` → превью (Main) или сразу с «Отменить» (InTask/Notes). Модель никогда не меняет данные напрямую — только через `apply`, где проверяются id, даты, дубликаты.

**Провайдер по умолчанию — Yandex AI Studio** (`ai/Llm.kt` — единая точка, `ai/Yandex.kt` — клиент, OpenAI-совместимый API, модели `gpt://<folder>/<name>/latest`). Причины: 152-ФЗ и оплата из РФ. Каталог в облаке — `margin` (отдельно от vuzburo), ключ сервисного аккаунта `margin-app`.
- Режим «Гибрид» (по умолчанию): простые фразы → `aliceai-llm-flash`, сложные (`Assistant.isComplex`: несколько дел, идеи/заметки, «разбей», длинные) и умные запросы (бриф, обзоры) → `deepseek-v4.1-flash`. «Экономно» — только Alice, «Точно» — только DeepSeek.
- Голос: Yandex SpeechKit v1 (0,1626 ₽ за начатые 15 с), офлайн — Whisper на телефоне.
- OpenRouter остался альтернативой в настройках (Gemini Flash-Lite / Sonnet / gpt-audio-mini).
- Экономика (замеры октябрь 2026, 13 фраз × прогоны, «шумный» ежедневник): гибрид 26/26, ≈0,35–0,47 ₽ за сообщение; только Alice 24/26, ≈0,28 ₽; только DeepSeek 26/26, ≈0,64 ₽. YandexGPT Lite (24/39) и Pro 5.1 (1,9 ₽/сообщ.), Qwen3.6 и gpt-oss — не подошли. Скидку на кэш Яндекс не гарантирует — считать без неё.
- Расход на токены держится на трёх вещах — не ломать: компактная схема без null-полей и стабильный префикс (правила+схема в начале), отбор контекста на телефоне (`Assistant.context(query=…)`: скелет недели + до 10 связанных задач + до 3 заметок), повтор при испорченном JSON (`Assistant.isBroken`, `Processor.askPlan`).
- Сравнение моделей: `YA_LIVE=1 NOISE=1 RUNS=2 DEBUG=1 MODELS="hybrid,aliceai-llm-flash,deepseek-v4.1-flash" ./gradlew :app:testDebugUnitTest --tests '*YandexCompareTest*' --rerun-tasks -i` (ключ из `~/.yc_margin_key`, `~/.yc_margin_folder`).

## Сборка

```
JAVA_HOME=/opt/homebrew/opt/openjdk@17 ./gradlew assembleRelease
```
- SDK: `/opt/homebrew/share/android-commandlinetools`, NDK 27.3.13750724, CMake 3.31.6, только arm64-v8a.
- APK кладётся на рабочий стол с номером версии в имени: `~/Desktop/Margin-<версия>.apk` (предыдущий оттуда убирается, все версии — в `releases/`); при выпуске повышать `versionCode`/`versionName` в `app/build.gradle.kts`.
- Подпись: `release.jks` + `keystore.properties` — **не удалять и не менять**, иначе обновление не встанет поверх.
- `secrets.properties` (`OPENROUTER_KEY`, `YC_KEY`, `YC_FOLDER`) зашивается в APK → это личная сборка, APK никому не отдавать. Коммерческая версия: ключей в APK нет, приложение ходит через посредника в Яндекс Облаке (Cloud Functions + API Gateway, ключ в Lockbox, вход пользователя, проверка подписки RuStore на сервере, лимиты на пользователя, правила промпта на сервере).
- debug-сборка имеет суффикс `.debug` и ставится рядом с release.

## Версии и откат

Код в локальном git (без удалённого репозитория). **При каждом выпуске** (после повышения `versionCode`/`versionName` и успешной release-сборки):
```
cp app/build/outputs/apk/release/app-release.apk releases/Margin-<версия>.apk
rm -f ~/Desktop/Margin-*.apk ~/Desktop/Margin.apk && cp app/build/outputs/apk/release/app-release.apk ~/Desktop/Margin-<версия>.apk
git add -A && git commit -m "<версия>: <что изменилось>" && git tag v<версия>
```
- `releases/` — архив APK по версиям (в git не входит: внутри зашиты ключи).
- Откат кода: `git checkout v3.5 -- .` (или `git log --oneline`, `git diff v3.5`). Старый APK ставится из `releases/` без пересборки; поверх более новой версии — только через удаление приложения (Android не даёт понизить versionCode), данные перед этим выгрузить архивом.
- В git не входят: ключи (`secrets.properties`, `keystore.properties`, `*.jks`), `third_party/`. whisper.cpp восстанавливается так: `git clone https://github.com/ggml-org/whisper.cpp.git third_party/whisper.cpp && git -C third_party/whisper.cpp checkout 60c0be6ac8fa71b1a2ae2dd938a31a34a508e774`.
- `release.jks` + `keystore.properties` существуют в одном экземпляре — их копия должна храниться вне этого Mac.

## Проверка

- Защита от лишних правок ИИ, даты повторов, заглавные буквы: `./gradlew :app:testDebugUnitTest --tests '*GuardsTest*'` (офлайн, бесплатно) — гонять после любой правки `Assistant.apply`.
- Фразы, на которых ошибались ИИ-тестировщики (октябрь 2026): `YA_LIVE=1 RUNS=3 MODELS=hybrid ./gradlew :app:testDebugUnitTest --tests '*YandexCompareTest.testerCases*' --rerun-tasks -i` (≈15 ₽). Итог 3.10: старый сценарий 42/42, фразы тестировщиков 23/24.
- Пересланные сообщения (чужие слова → «ждём», «Я: пришлю» → обещание, счёт → задача): `YA_LIVE=1 RUNS=2 ./gradlew :app:testDebugUnitTest --tests '*ForwardLiveTest*' --rerun-tasks -i`. Итог 3.17: 14/14.
- ИИ-тест «глазами пользователя»: агенты-персоны управляют эмулятором через adb-скрипты (скриншот → тап), ввод кириллицы — через share-intent в главное поле. Полезно после крупных изменений интерфейса; живые люди всё равно нужны.

- Живой тест ИИ (несколько центов): `MARGIN_LIVE=1 OPENROUTER_KEY=$(sed -n 's/OPENROUTER_KEY=//p' secrets.properties) JAVA_HOME=/opt/homebrew/opt/openjdk@17 ./gradlew :app:testDebugUnitTest --tests '*AssistantLiveTest*' --rerun-tasks -i`. После правок промпта прогонять 2–3 раза: быстрая модель нестабильна, одна удача ничего не доказывает.
- Whisper на устройстве: `./gradlew connectedDebugAndroidTest` (качает модель 60 МБ; `-Pandroid.testInstrumentationRunnerArguments.model=small` — 190 МБ).
- Эмулятор: AVD `calc35` (arm64). Русский интерфейс: `adb shell cmd locale set-app-locales ru.anjeib.margin --locales ru-RU`. Кириллицу удобнее подавать через share-intent: `adb shell "am start -n ru.anjeib.margin/.MainActivity -a android.intent.action.SEND -t text/plain --es android.intent.extra.TEXT '…'"`.
- Изменения интерфейса проверять скриншотом в эмуляторе (светлая и тёмная тема: `adb shell cmd uimode night yes/no`).
